# midjourney-fanart

通用的 Midjourney 角色同人创作 Skill：从创作想法、内容系列和画风设计，到完整提示词，再根据用户反馈与返图迭代。

用户提供角色参考图，AI 统筹提示词，用户到 Midjourney 生成。角色资料不留档，最终交付以完整英文提示词和简短中文附图说明为主。

## 使用

在支持 Agent Skills 的 AI 工具中，按该工具的方式载入整个 `midjourney-fanart` 文件夹。其他环境可读取 [SKILL.md](SKILL.md)，并按任务提供它链接的资料文件；需要分析图片时，应使用具备图像理解能力的环境。

Skill 使用自然语言与相对路径，不依赖特定 AI 平台、脚本或联网能力。文件无法直接编辑时，AI 应输出更新后的模板正文供用户保存。

可直接表达需求，例如：

> 根据我提供的角色图，设计一个婚誓系列。风格还没确定，先推荐方向，再帮我完成 Midjourney 提示词。

> 新增一个可以跨角色复用的“雨后赴约”系列，已有模板不合适就重新设计。

> 这是返图。我喜欢配色和服装，但人物太小、表情太冷淡。保留满意部分，修改完整提示词；如果是模板规则的问题，一起调整模板。

## 仓库结构

```text
SKILL.md                  入口与统筹规则
references/midjourney.md  定稿的模型、参考图和参数用法
references/feedback.md    结合用户反馈分析返图、选择修改范围
series/_template.md       新建内容系列的格式
styles/_template.md       新建风格模板的格式
```

`series/` 与 `styles/` 初始仅包含建模格式。具体系列和风格按后续需求新增，可以使用中文文件名；不会把示例主题自动登记为用户已选定模板。

## 维护

- 内容系列定义“画什么”，风格定义“怎样画”，分别保存并可组合。
- 用户要求新增或修改可复用方案时，更新对应模板；未确定的探索留在对话中。
- 当前模型用法按 2026-10-26 的官方资料定稿，后续由用户发起更新，不自动查询或设置缓存期限。
- 返图迭代优先遵循用户反馈，区分本张修改与可复用模板调整，记录真实验证状态。
- 使用 Git 管理修改历史；GitHub 的提交与推送按用户授权执行。

格式依据：[Agent Skills Specification](https://agentskills.io/specification)。Midjourney 官方来源与适用模型详见 [定稿用法](references/midjourney.md)。
