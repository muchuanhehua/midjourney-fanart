# 返图与用户反馈

## 先明确用户的修改目标

从反馈中提取三类信息：满意并需保留、不满意并需修改、希望尝试但尚未确定。用户只说“不像”“太普通”等模糊意见时，结合图中具体表现提出有助于选择的解释，不让用户自己定位专业原因。

反馈明确时直接改。对用户已经满意的画风、姿态或服装，不因 AI 自己偏好而一并重做。用户在迭代中改变目标时，以最新明确反馈为准。

## 对照材料定位问题

结合实际可见的返图、原提示词、所用模板与用户参考图，检查：

- 人物辨识：发型、轮廓、标志物等是否符合用户期望。
- 内容表达：主题动作、服装逻辑、关系和道具是否成立。
- 构图与注意力：景别、遮挡、人物数量和主体重点。
- 画风表现：线条、上色、色彩关系、明暗与纹理。
- 文字与设置：是否存在冲突描述或不匹配的参考方式。

区分图中可观察事实与原因推测。例如，“画面只到膝盖”是观察，“鞋子描述不足导致裁切”是待验证解释。缺少图片时可以根据文字反馈修改，但不声称看到了具体视觉缺陷。

## 选择修改范围

| 问题范围 | 应修改的位置 |
| --- | --- |
| 本张姿态、裁切、局部服装或个人偏好 | 本次完整提示词 |
| 系列共同规则持续无法表达主题，或用户明确调整系列 | 对应 `series/` 模板及本次提示词 |
| 风格定义不清、规则冲突，或用户明确改变画风 | 对应 `styles/` 模板及本次提示词 |
| 参数或参考图放置与本次目标不符 | 本次生成说明与必要参数 |

单张图的偶发瑕疵不足以证明通用模板有错。可以提出假设并局部调整，不把一次尝试变成所有后续作品的硬约束。

模型文档的更新由用户发起；局部返图问题不触发整套版本资料重写。

## 交付修改

简短说明“根据你的反馈，保留什么、改变什么”，给出完整新版提示词和仍需附带的图片说明。涉及可复用模板时，说明具体规则改动；没有文件编辑能力则提供完整替换正文。

优先修改能解释当前问题的部分，保留已成立的设计。必要时给出比较方案，但不默认生成多套候选增加用户负担。
